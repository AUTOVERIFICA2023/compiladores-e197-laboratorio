🎯 ¿Qué debes construir?

No es copiar una calculadora: debes desarrollar un módulo nuevo dentro de tu aplicación existente de PythonAnywhere.

1. Fuente
2. Intermedio
3. Python final
4. PDF
  1. Formulario web con variables editables y validaciones.
  2. Mostrar al menos dos expresiones relacionadas con tu tema.
  3. Producir automáticamente código intermedio con temporales t1, t2….
  4. Generar código Python final legible, según las expresiones.
  5. Calcular y contrastar resultados mediante operaciones controladas.
  6. Generar un PDF descargable con evidencia del proceso.

Ojo: no se acepta un PDF fijo ni un resultado escrito a mano. Si cambian los datos, cambian los cálculos y el informe.

🧩 Ejemplo guiado: así funciona el módulo

En lenguaje natural: una tienda vende tres artículos de $20.000 y aplica $5.000 de descuento. Primero multiplica, después resta y obtiene $55.000.

Expresión fuente

total = (precio * cantidad) - descuento

Código intermedio

t1 = precio * cantidad t2 = t1 - descuento total = t2

AHORA EN PYTHON · Código final

precio = 20000 cantidad = 3 descuento = 5000 t1 = precio * cantidad t2 = t1 - descuento total = t2 print(total) # 55000

Python es el lenguaje de destino didáctico; no lo confundas con código máquina.
